# Exercise 1 — Prompting for a Test Suite

Write `parse_price(s)` in `starter.py`: given a price string like
`"$1,234.56"`, return it as a float. Prompt the assistant for an
implementation, then prompt it for a test suite. Run the tests against
the implementation, then ask yourself: do the tests actually cover every
kind of price string you can think of? If not, refine your prompt (ask
for edge cases explicitly, ask what assumptions it made) until they do.
Record what you tried and why in `NOTES.md`.

Run `pytest` from inside this directory, not the repo root.
